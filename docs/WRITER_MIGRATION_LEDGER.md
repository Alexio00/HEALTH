# Сопоставление канонического журнала миграций Writer

Supabase фиксирует версию миграции по реально установленной временной метке. Подготовительные SQL-файлы ранее имели другие временные отметки; репозиторий приведён к установленным версиям:

| Версия проекта | Установленная версия | Миграция |
|---|---|---|
| 20261012200609 | 20261012203140 | health_writer_standby_v1 |
| 20261012203258 | 20261012203324 | health_writer_private_rls_and_operator_roles |

Текст SQL не менялся, повторного применения миграции и исправления серверного журнала не было. Исходные журналы принятия сохраняют названия кандидатов и хеши.

Ещё три уже установленные исторические миграции (планируемые препараты, права ограниченного читателя полного архива, уточнение нативного чтения) были добавлены в файловую историю под фактическими версиями, без новых клинических строк/прав. В момент согласования каталог покрывал все **15** установленных версий. Актуальную полноту проверять повторно через Supabase `list_migrations`, а не предполагать по этому датированному документу.

Восстановление из полного принятого архива — отдельный путь от повторного построения схемы из файлов; при восстановлении сверяются полные отпечатки таблиц, ролей и данных.
