# Проверка документации HEALTH — 13.10.2026

**Тип:** технический аудит документации; не является клиническим разрешением или Writer reacceptance. Оригинальные исторические свидетельства не удалять.

## Объём и результат

Просмотрено дерево `main` на принятом Writer SHA, включая 40 Markdown-файлов, 5 workflows, структуру миграций и документацию ветки `pwa`. Почти все 40 Markdown-файлов `main` написаны по-английски. Полный перевод исторических спецификаций **не выполнен**: он должен сохранять точные значения, юридический смысл и ссылки на доказательства. Этот аудит не объявляет всю документацию русскоязычной.

В данной документационной ветке переведены/обновлены `README.md` и `docs/CURRENT_DOCUMENTATION.md`. Остальные тексты требуют пофайловой проверки и перевода без изменения технической семантики.

## Обнаруженные несовпадения и предотвращение ошибок

1. В `docs/PROJECT_STATE.md` и `docs/PROJECT_MANUAL.md` находятся публичные снимки. Живые **приватные** HealthDB Project State/Manual имеют приоритет. Их нельзя перезаписывать исходя из исторических GitHub-снимков.
2. `MIGRATION*`, `FULL_MIGRATION_PLAN.md`, `MVP_*`, ранние `AI_WRITE*` и `WRITE_PATH_DECISION.md` описывают события и кандидатов до принятого 13.10.2026 перехода на Supabase. Они исторические, **не текущая инструкция к запуску миграции**.
3. Действующий Writer закреплён за точным SHA `main`. Слияние даже русского README изменит SHA и должно быть согласовано с текущим циклом принятия Writer.
4. Публикация PWA теперь идёт из защищённой ветки `pwa`. Старый main workflow Pages ещё присутствует; его отключение подготовлено в Draft PR #39, отдельно от этой документационной работы.
5. Независимая защита PR scope ещё имеет HIGH-ограничение, сохранённое в [Issue #50](https://github.com/Alexio00/HEALTH/issues/50).
6. Дополнительная Supabase MFA / AAL2 и закрытость оболочки сайта пока проектируются: [Issue #58](https://github.com/Alexio00/HEALTH/issues/58). Публичный Pages не означает публичные медицинские данные.
7. Русская инструкция развертывания для нового пациента пока не завершена: [Issue #53](https://github.com/Alexio00/HEALTH/issues/53). Не выдавать текущий README за полное руководство установки.

## Критерии окончательного закрытия

- У всех пользовательских актуальных руководств есть полноценный русский текст; исторические англоязычные источники обозначены архивными и имеют русскую аннотацию/проверенный перевод без потери оригинала.
- Сверены текущие SHA, статус Writer, расписание резервирования, правила Pages, граница секретов и все действующие инструкции.
- Проверены относительные ссылки и ссылки между HEALTH/SHEDULLER; нет противоречий с приватными Manual/State.
- Изменения `HEALTH/main` слиты только после согласованного нового принятия Writer SHA; изменения `SHEDULLER/main` — после проверки pin резервного архива.
