# Служебная ветка `scheduler`

Эта ветка используется только для контрольных коммитов активности публичного GitHub-репозитория HEALTH. Она **не является веткой публикации приложения, Writer или SQL-миграций**.

Раз в 15 дней (при штатной работе и отсутствии ручных вмешательств) GitHub Actions из доверенной основной ветки создаёт здесь пустой Git-коммит. Содержимое файлов, медицинские данные и принятый код не меняются.

Контроль пропусков: независимый scheduled workflow выдаёт `FAIL`, если последний коммит старше 18 дней. Email о неуспешном GitHub Actions приходит только при включённых уведомлениях владельца; при общем отключении расписаний оба задания могут молчать, поэтому это **не внешний гарантированный мониторинг**.

Нельзя выполнять merge этой ветки в `main` или `pwa`. Не считать периодические коммиты доказательством, что GitHub **гарантированно** не отключит расписание после 60 дней: это распространённый практический приём, но не отдельная гарантия GitHub.
