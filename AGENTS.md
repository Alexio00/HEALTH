# Правила веток HEALTH (проект для согласования)

- Изменения веб-интерфейса выполняются из актуальной ветки `pwa` с PR в `pwa`; GitHub Pages выпускается из `pwa`.
- Writer и серверные изменения выполняются через отдельные ветки от `main`, с PR в `main`.
- Смешанные PR разделяются на независимые части; перед переносом старого PR требуется проверить различия с актуальной базовой веткой.
- Принятый SHA Writer привязан к `main`. Любой merge в `main`, даже документационный, требует согласованного повторного принятия версии до продолжения медицинских записей.
- Временный риск: прежний Pages workflow в `main` может перезаписать опубликованный сайт.
- Медицинские данные и секреты не публикуются в GitHub. Нельзя перезаписывать чужие ветки.
- Подробная процедура: `docs/PWA_RELEASE.md` из ветки `pwa`.

Этот файл подготовлен в отдельной ветке. Он не является разрешением немедленно слить PR в `main`.
